# Array
```cpp

type name [elements];

该数组大小在编译的时候就确定了

```

### 初始化数组
```cpp

int foo [5] = { 16, 2, 77, 40, 12071 }


int bar [5] = { 10, 20, 30 };
    前三个被初始化为 10,20,30 后面两个使用0填充


int baz [5] = { };
    数组全部被0填充




int foo [] = { 16, 2, 77, 40, 12071 };
    cpp 允许 [] 不写具体的数字  会在编译的时候自动分配一个大小



定义在命名空间中 的数组 总是被初始化(不是定义在函数)

```
