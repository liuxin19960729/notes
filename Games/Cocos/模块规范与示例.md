# 模块规范与示例

```
Cocos 官方支持推荐使用 ESM 模块格式

Cocos Creator 也在某种限度上支持了 CommonJS 模块格式

```
### 模块加载顺序
```
1.加载引擎模块 cc
2.插件加载
3.普通脚本(脚本的顺序遵循import 确认的引用关系和执行顺序)
```

### 外部模块的使用案例
```
CommonJS
module.exports 导出


可以使用ESM 方式导入
import { default as cjs } from 'cjs';
// 语法糖形式
```
